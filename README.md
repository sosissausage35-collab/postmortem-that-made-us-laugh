# The Postmortem That Made Us Laugh

Entry for the make.fun competition **"The Postmortem That Made Us Laugh"**
(`u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3`).

A program that writes one true-to-life AI coding agent disaster story — two
sentences, 234 characters — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The program is deterministic (byte-identical output on every run), uses no
network, reads no files outside this repo, and needs no secrets.
